# Motion library — как выбирать эффекты (для `aphelia-storyboarder`)

Цель: ролик, который **не отпускает**. Картинка меняется каждые 2–5 с, каждое ударное слово получает визуальный ответ, ни один приём не повторяется два раза подряд. Эффекты выбирает агент — по смыслу бита, не по списку. Полный перечень того, что умеет движок (переходы, слои, камера, субтитры, custom-компоненты), — `shared/remotion-capabilities.md`.

## Шаг 0. Анализ ролика (до первой сцены)

Прочитай `script.json` целиком и запиши в начало фрагмента 6 решений — они делают ролики разными от прогона к прогону:

1. **Жанр и тон** — новость / расследование / разбор / мотивация / ирония / финтех (одно слово + почему).
2. **Стиль-пресет** (таблица ниже) → `style_preset`, `style.accent`, `style.danger`, `captions.style`. Пресет не должен совпадать с предыдущим роликом в `aphelia-memory/runs/*/storyboard.json` — проверь.
3. **Ритм** — сколько сцен, где панчи (обычно 2–3), где «выдох» (fade/handheld).
4. **Словарь переходов ролика** — 3–4 типа из десяти, которые будут основой (например: newsroom → push/wipe/flash; расследование → fade/clock/zoom; ирония → flip/iris/slice). Остальные — точечно.
5. **Музыка** → `music-brief.json` (жанр/темп по `shared/music-contract.md`) и `bgm.src = "audio/bgm-generated.mp3"`.
6. **Звуковая палитра** — 8–12 SFX из `templates/audio/sfx-catalog.json`, подобранных по словам сценария (деньги → `paper-move-quick`/`ui-confirm-tone`, замок → `lock-quick`, код → `keyboard`, время → `clock-tick-single`, провал → `glass-break-hammer`…). Записать список; повторять один звук ≤ 3 раз.

Если для бита нужен эффект, которого нет ни в слоях, ни в переходах — пиши `custom`-компонент (remotion-capabilities § 7), а не подгоняй смысл под каталог.

## Ритм ролика 60–90 с

- 14–24 сцены. Хук ≤ 3 с. Средняя сцена 3–4 с. Одна «длинная» сцена ≤ 9 с — только с внутренним движением (список по словам, столбики, видео).
- Каждые 10–15 с — смена «фактуры»: стикер → цифры → браузер → список → инверсия → стикер.
- 1–3 инвертированных сцены (`bg: "ink"`) на самых сильных фразах; 0–1 лаймовая (`accent`) под вывод/CTA.
- Камера: минимум в половине сцен есть второй ключ. `crash` — на слове-ударе (не чаще 1 раза в 6–8 с, иначе тошнит). `shake` 8–14 px — вместе с `impact/bass/stomp`. Zoom при crash 1.08–1.15, если в сцене есть плашки/списки; 1.2–1.25 — только в сцене-реакции (крупный персонаж, без stage-текста).

## Архетипы сцен (готовые связки)

| Архетип | Когда | Слои | Камера / переход |
|---|---|---|---|
| **Хук-цифра** | первая сцена, есть число | `kicker` + `bignum` (circle, size 300–340) + `headline` (2 строки, `hl` на главном) + `image` char-shock (`pop`, `float`) + `stamp` на последнем слове | `crash` zoom 1.18 на штамп |
| **Заявление** | тезис без числа | `headline` `slam` или `words` + `image` char (`slide` сбоку) + `scribble` underline на ключевом слове | `push` вход, лёгкий дрейф |
| **Таймлайн** | «сначала… потом…» | `kicker` «ШАГ 1/2/3» + `headline` + `image` ill (`wipe` или `drop`) + `arrow` к объекту (`marker` SFX) | `push` в одном направлении для всех шагов серии |
| **Сравнение** | два-три числа | `headline` + `bars` (items по `at_word`, разные `color`) | `iris` вход из центра bars |
| **Чек-лист** | 2–5 пунктов «что делать» | `headline` + `list` (`bullet: check`, `at_word` на каждом пункте) + `image` char-point слева | статичная камера, `tick` на пункты |
| **Цитата** | прямая речь компании/человека | `bg: paper` или `ink`, `quote` + `image` char-shrug/think (`swing`) + `label` источник | `zoom` вход |
| **Доказательство** | есть скрин/страница источника | `headline` + `video` (браузер, `rot` −2…2) + `image` char (`slide` снизу поверх рамки) | `push up`; камера медленно наезжает на рамку |
| **Панч** | самая сильная фраза | `bg: ink`, `headline` `slam` (size 96–120, `hl`), опционально `check`/`cross` | `flash` вход, `shake` 12 |
| **Реакция** | эмоция к факту | `image` char (`zoomin` крупно, h 1000–1200) + `stamp` | `crash` zoom 1.25 на лицо |
| **Вывод / CTA** | последние 2 сцены | `bg: accent`, `headline` `words` + `list` из 2–3 правил, затем `image` char-celebrate (`drop`) + `label` «подпишись — …» | `slice` вход, `success` SFX |
| **Доля / статистика** | «каждый третий», «40 процентов» | `shape: pie` (`progress` 0.4) + `bignum` рядом + `label` | `iris` вход, `clock-knob-spin` |
| **Голос / звук** | речь про аудио, музыку, озвучку | `waveform` (src vo.mp3, **`bars`: 16 / 32 / 64** — степень двойки) + `image` ill-speaker (`spring`) | `fade`, `handheld` 3 |
| **Время / дедлайн** | «12 дней», «до конца недели» | `clock` переход + `bignum` дней + `shape: pie` тающий | `clock`, `clock-tick-single` |
| **Взрыв / вау** | рекорд, «впервые», шок | `shape: burst` (accent) за `stamp` + `image` char-shock `spring` + `trail` | `flash`, `impact-cine-big`, shake 12 |
| **Свой приём** | ничего из списка не передаёт смысл | `custom` компонент (например счётчик, конфетти, карта) | по смыслу |

## Правила разнообразия (валидатор предупреждает)

Все пункты ниже проверяет `validate_storyboard.py` (warnings): повторы переходов и анимаций, лишние `stamp`/`bignum`, длина заголовка, сцены без визуала, повтор стикера в соседних сценах и > 2 сцен на один `src`, два `crash` ближе 5 с. Warning — не ошибка, но каждый либо устраняется, либо объясняется во фрагменте.

1. Переходы: не один и тот же тип подряд; ≥ 3 разных типов на ролик из десяти (`push`, `wipe`, `fade`, `flip`, `clock`, `iris`, `zoom`, `flash`, `slice`); серия шагов может держать `push` в одном направлении — это осознанное исключение (объясни во фрагменте). «Громкие» (`flash`, `slice`, `zoom`) не подряд.
2. Анимации стикеров: ≥ 3 разных на ролик из десяти (`pop`, `spring`, `spin`, `wipe`, `slide`, `run`, `shake`, `swing`, `zoomin`, `drop`); `pop` — не больше половины; `trail` — на 1–2 быстрых движениях.
3. Не более одного `stamp` и одного `bignum` на сцену; штамп — на слово, которое реально ударное.
4. Заголовок ≤ 48 символов, максимум 3 строки; всё, что длиннее, — в субтитры, они уже есть.
5. Каждая сцена имеет визуал (стикер / цифра / список / столбики / видео / стрелка), не только текст.
6. Соседние сцены не используют один и тот же стикер; один стикер ≤ 2 сцен за ролик.
7. Слои появляются **по словам** (`at_word`), а не все в 0 с. Первый слой сцены — в 0.
8. Стикеры — крупно: персонаж h 780–1100, иллюстрация w 640–900. Мелкие картинки «в квадрате» запрещены.
9. `crash` — не чаще одного раза в 6–8 с (валидатор ругается при < 5 с). Между двумя crash ставь `shake` без crash или `smooth`.

## Композиция кадра

- Kicker: `x` 64, `y` 196. Заголовок под ним — **не ближе 60 px**: `y` ≥ 260 (валидатор предупреждает при зазоре < 1.3·size kicker ≈ 57 px). Без kicker заголовок `y` 200–260. `x` 64, `w` 560–950; если стикер справа — `w` ≤ 600.
- Персонаж справа: `x` 600–680, `y` 520–620. Персонаж слева: `x` 40–90.
- Иллюстрация по центру: `x` 90–140, `y` 620–760, `w` 800–900.
- Цифра: `y` 236–300; с `deco: circle` левый край `x` ≥ 0.2·size + 20 (для size 300 → 80, 340 → 88), правый край `x + ширина числа + 60` ≤ 970 при zoom 1.0 — иначе обводка срезается краем (todo-econ: «6$» при x 580 и zoom 1.1 — круг за кадром). Штамп: рядом с объектом, `rot` от −9 до 9.
- Списки: `x` 80, `y` 640–720, `w` 900, size 48–56, ≤ 5 пунктов.
- `hl` (маркер) читается на любой палитре: paper → лайм, ink → красный, accent → белый, danger → чёрный. Отдельно менять цвета не нужно.
- Нижние 1480–1700 px заняты субтитрами — туда только ноги персонажа.

### Камера и проекция stage-слоёв

При `zoom z` в точке `(cam.x, cam.y)` слой с холста `(x, y)` оказывается на экране в `screen_x = 540 + z·(x − cam.x)`, `screen_y = 960 + z·(y − cam.y)`. HUD (`kicker`, `headline`) камера не двигает; всё остальное — двигает. Отсюда три правила:

- **Нижние плашки** (`label`, `stamp`, `list`, `quote`, `bignum`): `y ≤ cam.y + 400/z`, иначе плашка проецируется в зону субтитров (1480+). Примеры: cam.y 800, z 1.08 → y ≤ 1170; cam.y 900, z 1.1 → y ≤ 1260. Константа «y ≤ 1300» не работает при наезде.
- **Левый край**: при `cam.x` > 540 и z ≥ 1.1 плашки с `x` 48–96 уезжают за кадр. Точка crash/наезда — `cam.x` 500–580, если слева есть текст; zoom 1.08–1.15, не 1.2+. Смотрим «в лицо» стикеру справа — ставь стикер ближе к центру, а не двигай камеру к 700.
- **Правый край**: `screen_x` правого края слоя (x + w или оценка по длине текста) ≤ 1068.

Валидатор проецирует bbox каждого stage-слоя по **каждому** ключу камеры и предупреждает «leaves the frame» / «under the captions» — читай `storyboard-validation.json`, а не считай в голове. Камера интерполируется между ключами, поэтому промежуточные положения тоже проверяются guardian по late-кадрам (88 % сцены).

## Звук

- Каждая сцена: 0–2 SFX (3 — потолок). Переходы озвучиваются автоматически и ротируются; явный `transition.sfx` — если хочется конкретный характер.
- **Подбор по смыслу текста**, не по привычке: открой `templates/audio/sfx-catalog.json` (186 звуков, теги на русском) и ищи по словам бита — «замок» → `lock-quick`/`lock-digital`, «код» → `keyboard`/`typewriter-digital`, «деньги» → `paper-move-quick`/`ui-confirm-tone`, «время» → `clock-tick-single`/`countdown-bleeps`, «крах» → `glass-break-hammer`, «идея» → `sparkle-touch`, «аплодисменты» → `applause-rhythmic-loop`, «сердце/риск» → `heartbeat-single`, «ретро/вспомним» → `tape-rewind-fast`, «страница/отчёт» → `paper-page-turn`.
- Удары (`bass-hit-short`, `impact-cine-big`, `stomp-apocalyptic`, `hit-fast-exciting`) — только под штамп/crash/инверсию; стикеры — `pop`/`pop-electric`/`ui-message-pop`; стрелки/обводки — `marker-pen-line`/`pen-write-paper`/`chalk-line`; пункты списка — `clock-tick-single`/`switch-tap`/`ui-select-modern`; техно — `data-compute`/`data-scan`/`glitch-virtual-quick`/`hitech-bleep`; вывод/CTA — `ui-success-soft`/`chime-crystal`/`sparkle-poof-hit`/`clap-single`; `riser-cine` за 2–3 с до главного панча — один раз.
- Один и тот же звук ≤ 3 раз на ролик (валидатор предупреждает). От ролика к ролику звуковая палитра меняется вместе со стиль-пресетом.
- BGM: всегда генерируем под настроение (`music-brief.json` → ACE-Step, см. `shared/music-contract.md`). Библиотечные треки — только запасной вариант. Громкость 0.25–0.45.
