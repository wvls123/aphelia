# Voice contract — озвучка Aphelia

## Модель

`Qwen/Qwen3-TTS-12Hz-1.7B-*` — актуальное семейство Qwen TTS (релиз 22.01.2026; проверено по Hugging Face: новее в аккаунте Qwen нет). Используем **две** модели:

1. **VoiceDesign** (`1.7B-VoiceDesign`) — один раз проектирует фирменный голос диктора по текстовому описанию → `voices/narrator-ru/ref.wav` (+ `ref.txt`, `meta.json`). Команда: `python scripts/voice.py design-voice --name narrator-ru [--instruct "..."]`. Из 6 дублей выбирается самый чистый (Whisper ≥ 0.9) и быстрый.
2. **Base** (`1.7B-Base`, клон по 3 с) — озвучивает сценарий, клонируя референс. Тембр одинаков во всех предложениях и во всех роликах.

Почему не клон Edge TTS: клон копирует и «роботность» источника. Референс от VoiceDesign — живой голос.

## Ударения

- Готовая библиотека **ruaccent** (Den4ikAI, turbo3.1 + полный словарь): расставляет `+` с учётом омографов (`з+амок / зам+ок`). Позицию ударения **не** пишем руками для обычных русских слов.
- `shared/voice-lexicon.json`: `qwen_force_marks` — список слов, которые Qwen ломает (метку берём из ruaccent); `ruaccent_custom_dict` — только заимствования, которых в библиотеке нет или она ставит неверно (`токены`, `кёрсор`). Файл ролика `stress-overrides.json` перекрывает ключи custom_dict, не заменяет словарь ruaccent.
- В озвучку бренды из словаря уходят **латиницей** (`GitHub`, `Alibaba`, `LTX`) — Qwen так читает их лучше, чем «Гитхаб» / «Эл-Ти-Икс». `normalize()` перед Whisper сводит латиницу обратно к фонетике, чтобы сравнение не ломалось.
- В текст для модели ударение передаётся **комбинируемым акутом U+0301** после гласной (`замо́к`); `+` и `ЗАМО'К` модель игнорирует (A/B 50 % = случай). Тот же акут проставлен в `ref.txt` референса.
- **Метки — не по умолчанию.** Замер на run dreamx-creator (2 прогона, 12/12 предложений): акут в клон-дубле Qwen3-TTS Base в ~1/3 случаев даёт слышимый глайд после ударной гласной (Алиба́бы → «Алибоюбы», оди́н → «Адион», Минима́кса → «минимайуса»), а дубль без меток того же предложения Whisper слышит чисто — модель сама правильно ставит ударение в обычных словах и известных брендах. Старый A/B «79 % с акутом» мерил только ударение MMS, не чистоту слова, и переоценивал метки.
- Политика дублей `voice.py narrate` (`--marks overrides|homographs|none`, по умолчанию `overrides`):
  1. Первый дубль — **чистый** (без меток). Если Whisper подтверждает (`sim ≥ --min-sim`, длительность в лимите) и в предложении нет слов из `qwen_force_marks` / custom_dict / `stress-overrides.json` — принят.
  2. Метки ставятся **только** на слова из `qwen_force_marks` / `ruaccent_custom_dict` и на явный `stress-overrides.json` ролика; с `--marks homographs` — ещё и на словарные омографы (`зАмок/замОк`, `дЕли/делИ`, `вЕса/весА`) — включать, если в тексте омограф со смысловой разницей и чистый дубль его переврал. `--marks none` — вообще без меток и без MMS.
  3. Маркированный дубль **заменяет** чистый только если: `sim ≥ max(--marked-min-sim 0.97, sim чистого)`, каждое маркированное слово услышано Whisper **целым** (нет «Алибоюбы»), и MMS-проверка не противоречит (`stress ≥ 0.5`). Иначе остаётся чистый.
  4. Любой дубль с `sim < --min-sim` или сверх лимита длительности перегенерируется (до `--tries 3`).
- **MMS forced alignment — advisory.** Оценка «какая гласная длиннее/громче» шумная (~80 % на омографах, глайд принимает за ударение) → она больше не даёт бонус в score, а лишь блокирует маркированный дубль при явном противоречии. `voice-report.json → doubtful_stress` — список для ручного прослушивания, а не приговор: подтверждай по `heard` Whisper, а не по stress-оценке.
- Отчёт: `dump_takes.py` пишет `marks=1/0`, `sim`, `heard` для каждого дубля; `voice-report.json → marks_mode`, `marked_sentences`.

## Темп и чистота

- Каждое предложение генерируется отдельно, обрезается тишина, Whisper (`small`) проверяет текст; лишние слова/междометия → перегенерация (до 3 дублей).
- `normalize()` перед сравнением вырезает цифры и числительные **во всех падежах** («тридцати трёх», «шести»), а латинские аббревиатуры в heard приводит к названиям букв («LTX» → «эл ти икс»): Whisper пишет цифры и латиницу, диктор говорит словами — это не ошибка озвучки. Если `BAD` в `voice-report.txt` всё же держится только на цифрах/латинице в `heard` (новая форма числительного, незнакомая аббревиатура) — аудио принимается, слово добавляется в `NUMBER_WORDS`/`LATIN_NAMES`.
- Лимит длительности предложения: `0.11·букв + 0.9` с — ловит зависания и растянутую речь.
- Паузы между предложениями 0.12 с; итог ускоряется `atempo 1.06`, нормализуется до −15 LUFS, хвост 0.35 с.
- Целевой темп ~2.35 слова/с (замер; на dreamx-creator 2.47). 60–90 с ≈ 140–215 слов.
- Слова, которые модель систематически ломает («два-ка» → «два козы», «липсинку» распадается), — не лечить метками, а вернуть writer на переформулировку («два-кей», «синхронность губ»).

## Выход

`assets/vo.mp3` (48 кГц), `assets/vo-words.json` (Whisper word timestamps — основа `at_word`), `assets/vo-duration.txt`, `voice-report.json`.

## Команды

```powershell
python scripts/voice.py design-voice --name narrator-ru            # один раз / при смене голоса
python scripts/voice.py narrate --project aphelia-memory/runs/<slug>  [--tempo 1.06] [--tries 3] [--min-sim 0.74]
python scripts/voice.py narrate --project ... --marks homographs            # + словарные омографы (дели́/де́ли)
python scripts/voice.py narrate --project ... --marks none                  # совсем без меток и MMS
python scripts/voice.py narrate --project ... --marked-min-sim 0.99         # строже принимать маркированный дубль
python scripts/dump_takes.py aphelia-memory/runs/<slug>/voice-report.json   # читаемый лог дублей (marks, sim, heard)
```

В PowerShell не оборачивай `voice.py` в `2>&1 | Tee-Object`: предупреждения torchaudio/Whisper («SoX could not be found», Triton) идут в stderr и дают ложный exit code 1 при успешном JSON. Читай последнюю JSON-строку stdout или запускай через `cmd /c`.
