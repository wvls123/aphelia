## v5 — «SaaS / Swiss Pulse»

Светлые сцены (мятный radial glow, белые карточки) чередуются с тёмными (скрин GitHub + крупный белый заголовок).

Повторяемый каркас кадра:

1. **Kicker** сверху (маленький серый caps): «новый подход», «вход», «сверка», `FINAL OUTPUT`.
2. **Headline** 1–2 строки, жирный sans, почти на всю ширину.
3. **Центр** — UI-карта: YouTube→Claude, поле ссылки, чеклист с зелёными галками, сплит Claude | Gemini.
4. **Caption pill** внизу — почти дословная текущая фраза VO.

Приёмы:

- Карточки с тенью и лёгким 3D-наклоном.
- Зелёный акцент `#00E676`-класса: галки, обводка активного столбца, CTA.
- «SOURCE PROOF»-бейдж на кадрах со скрином README (`bradautomates` / Claude watch skill).
- Talking-head PiP в части сцен (борода, кепка) — **для первой итерации пайплайна выключен** (без стикеров/аватаров).
- Переходы мягкие: scale/opacity карточек, не жёсткий cut на каждом слове.

## v6 — «cartoon avatar»

Тот же сценарий и тайминг. Белый фон + перспективная сетка. Вместо UI-демо — иллюстрации и говорящий персонаж (борода, очки, фиолетовый свитер), кинетические подписи сверху с красным акцентом на ключевом слове. Битрейт выше из‑за детализированной графики. **Не цель первой итерации.**

## Моушн-анализ (покадровый, 10–30 fps)

Замерено через попиксельную разницу кадров (PIL/numpy):

- **Переходы — быстрые полнокадровые свайпы ~0.25–0.3 с.** На стыках (2.9 с, 6.3 с, 29.3 с) магнитуда движения всплескивает до 65–84 за 2–3 кадра и сразу затухает. Это push/swipe с сильным easing (expo), а не медленный fade.
- **Внутри сцен — постоянное микродвижение** (магнитуда 0.5–3): карточки доносятся, glow пульсирует, чеклист заполняется слева направо ~1 с. Кадр никогда не стоит.
- **Галки/плюс — pop с overshoot**, цифры набираются, стрелка дорисовывается.
- **Скриншоты источников** вставлены как «окно браузера» с бейджем SOURCE PROOF.

Этот профиль перенесён в оба движка: переходы 0.3 с `expo.out` / `springTiming`, ambient drift scale 1→1.035, count-up в stats, pop с `back.out` / overshoot-spring, браузерные рамки со скриншотами Habr и Xakep.

## Что переносим в конвейер

- Формат 1080×1920 / 30 fps / ~25–35 с.
- Голос ведёт монтаж: сцена = фраза или пара фраз.
- Модульные виды сцен: стрелка A→B, чеклист, большие цифры, сплит, CTA.
- Caption pill + kicker + headline.
- Без стикеров, без аватара, без talking-head.
- Рендер: HyperFrames (HTML+GSAP), визуальный язык как у Remotion-референса v5.
