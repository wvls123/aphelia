# Pitfalls — что уже ломалось в Aphelia и как не повторить

| Симптом | Причина | Что делать |
|---|---|---|
| Директор сам взял тему «MCP / контент-завод» и «переключился на Desktop\\Aphelia» | `/aphelia-new` без аргумента + чужие alwaysApply-правила (Kovcheg) + поиск исходников плагина | тема только из сообщения пользователя; нет темы — спросить и стоп; скрипты из `plugins/local/aphelia`, память в текущем workspace; `move_agent_to_root` запрещён |
| В ролике те же человечки, что в прошлом | illustrator копировал `templates/stickers/<name>.png`; Директор писал «библиотеку — одному экземпляру» | каждый run — GenerateImage по `_style-reference.png`; копировать готовые стикеры запрещено; в Task illustrator не писать «не генерируй» |
| Сценарий как релиз-нот / прайс | researcher не выделил вау-факты; writer взял changelog | в research раздел «Вау-факты»; writer строит хук из них, не из таблицы цен |
| Озвучка «робот», клон звучит как Edge TTS | клон копирует роботность референса | референс только от VoiceDesign (`voice.py design-voice`), не от синтетических TTS |
| «Э-э», «м-м», лишние слова в озвучке | стохастика Qwen | per-sentence Whisper-проверка + до 3 дублей (уже в `voice.py`); если BAD остался — переформулировать предложение |
| Ударение не там (зАмок/замОк, «подпешись», «токены») | модель не знает ударений; самописный словарь дублировал ruaccent | ruaccent turbo3.1 ставит `+`; `qwen_force_marks` только список проблемных слов; `ruaccent_custom_dict` — формы, где библиотека ошибается |
| Человек слышит неверное ударение, Whisper sim = 1.0 | Whisper не слышит ударение; чистый дубль всегда бил маркированный; MMS блокировал Афе́лия (got последняя гласная) | `stress-overrides.json` → маркированные дубли первыми; MMS не блокирует; побеждает целый маркированный дубль |
| Бренд кириллицей («Гитхаб», «Хаггинг Фейс») звучит криво | Qwen читает транслит как русские слова | в `say` бренды из `latin_brands` латиницей; `voice.py` сам переписывает кириллические формы; на экране — `phonetics` |
| `+`/`ЗАМО'К` нотации не работают | модель их игнорирует (A/B 50 %) | только U+0301 (79 %) |
| Ролик 28 с вместо 60–90 | короткий сценарий | `script_check.py` требует `min_seconds…max_seconds`; 2.65 слова/с |
| Whisper слышит «1200» цифрами | нормализация Whisper | `timeline.expand_whisper` раскрывает числа в слова; в script.txt числа только словами |
| `say/script mismatch` в timeline | сцены не покрывают текст дословно | `validate_storyboard.py` показывает позицию первого расхождения |
| `at_word not found` | слово из другой сцены / опечатка | `at_word` — слово из `say` этой сцены, без знаков |
| Стикер исчезает во время анимации | GSAP fromTo без `autoAlpha: 1` в `to` | всегда явный `autoAlpha` в обоих концах |
| Заголовок обрезан камерой | заголовок внутри `.cam` | kicker/headline — HUD-слой вне камеры (уже так) |
| Картинка «в квадрате» | не вырезана / серый фон | `cutout.py` + `transparent_ratio ≥ 0.35`; в storyboard только `cut/` |
| `timeline.py`: `unknown bgm audio/bgm-generated.mp3` | timeline запускается до генерации музыки | при `bgm-generated` достаточно `music-brief.json` — `render.py` сгенерирует трек перед рендером |
| Remotion: сцена B начинается раньше/позже слова | TransitionSeries: B стартует на τ раньше конца A | `Reel.tsx` считает `dur_A = startB − startA + τ`, переход занимает `[startB, startB+τ]`; не менять формулу без пересчёта |
| `custom layer component not registered` | файл `<run>/custom/<Name>.tsx` отсутствует или имя не PascalCase | `sync_remotion.py` строит реестр из файлов; имя компонента = имя файла = экспорт |
| Один и тот же лайм/whoosh/tech-house в каждом ролике | агент берёт дефолты | шаг 0 motion-library: пресет ≠ прошлый, `music-brief.json` под настроение, SFX по каталогу; валидатор предупреждает про дефолтный акцент и повторы звуков |
| Музыка вызывает Content ID | библиотечный трек | генерировать ACE-Step (MIT, коммерческое использование разрешено); библиотека — только fallback, и то Mixkit Free |
| Подсветка `mark` не видна (HF) | `@property --mk inherits:false` | `inherits: true` |
| PowerShell пишет UTF-16 в файлы | `>` редирект | писать файлы из Python; `common.say` печатает UTF-8 |
| Субагенты одной волны перетирают handoff | параллельная запись | только `fragments/<role>.md`, склеивает Директор |
| `assets.json` теряет записи при 2 иллюстраторах | одновременная запись | читай-модифицируй-пиши, перечитать перед записью; каждый пишет свои имена |
| `cutout-report.json` содержит только последний батч | параллельные `cutout.py` перезаписывали отчёт | `cutout.py` мержит отчёт по имени файла (исправлено); размеры для `assets-N.json` можно брать из PNG в `assets/cut` |
| Скринкаст 14–17 с при `--seconds 8`, в начале белый экран | Playwright пишет видео с создания контекста (загрузка, ожидание, клик по баннеру) | `record_scroll.mjs` отдаёт `scrollStartMs`, `capture_web.py` режет `-ss scrollStart−0.8 -t ≤10`, кодирует `-g 30` (исправлено); проверяй `qa/shot-*-0s.jpg` — первый кадр уже с заголовком |
| Cookie-баннер поверх скринкаста | кнопка «Хорошо/Понятно/ОК» не в списке селекторов | селекторы расширены в `record_scroll.mjs`; новая формулировка → добавить туда же, при необходимости generic `[class*=cookie] button` |
| Короткая страница (GitHub README) — прокрутка упирается в низ на 3-й секунде | фиксированный шаг 42 px | адаптивный шаг от `scrollHeight` в `record_scroll.mjs` (исправлено); статичный низ иногда и есть нужный кадр — фиксируй тайминг в `videos.json.notes` |
| Озвучка: «Алибоюбы», «Адион», «минимайуса» — лишняя гласная после ударной | акут U+0301 в клон-дубле Qwen3-TTS Base даёт глайд в ~1/3 дублей; MMS-оценка награждала артефакт | `voice.py`: чистый дубль первым, метки только для `stress-overrides.json` (`--marks overrides`), маркированный дубль заменяет чистый лишь при sim ≥ 0.97 и целом слове (исправлено); MMS — advisory, см. `shared/voice-contract.md` |
| Ложный `BAD` при верном аудио: heard «7 миллиардов против 33», «LTX» | `normalize()` знал числительные только в именительном, латиницу не транслитерировал | `NUMBER_WORDS` с косвенными формами + `LATIN_NAMES` (исправлено); если heard отличается только цифрами/латиницей — аудио принято, слово дописать в словарь |
| `voice.py` даёт exit code 1 в PowerShell при успешном JSON | «SoX could not be found», Triton-предупреждения в stderr + `2>&1 \| Tee-Object` | читать последнюю JSON-строку stdout; не оборачивать в Tee, либо `cmd /c` |
| Модель ломает слово в каждом дубле («два-ка» → «два козы», «липсинку» распадается) | несловарная/иноязычная лексема | не лечить метками — вернуть writer на переформулировку («два-кей», «синхронность губ») и переозвучить целиком |
| `hl` в headline невидим: чёрный прямоугольник на accent, белый на лайме | цвет плашки и текста Mark брались из одной палитры | `layers.tsx` Mark/Headline: цвет фрагмента по палитре (исправлено); `hl` можно оставлять на любом `bg` |
| Плашки/штампы срезаны левым краем или уходят под субтитры при наезде | камера проецирует stage-слои: `screen = 540 + z·(x − cam.x)`, `960 + z·(y − cam.y)`; storyboarder ставил `y` по константе «≤ 1300» | `validate_storyboard.py` проецирует bbox по каждому ключу камеры и предупреждает (исправлено); правило `y ≤ cam.y + 400/z`, `cam.x` 500–580, zoom 1.08–1.15 — `shared/motion-library.md` «Камера и проекция» |
| Круг `bignum` срезан правым краем | `x` 580 + ширина числа + обводка при zoom 1.1 > 1080 | правый край `x + ширина + 60` ≤ 970; валидатор ловит через проекцию |
| Столбики «1/0» вместо «0,69/0,63», bignum без «$» | `fmtRu = Math.round`, счётчик рисовал только число | `layers.tsx`: fmtRu хранит десятичные, Bignum рисует нечисловой хвост (исправлено); в storyboard дробные `bars.value` и «6 $» допустимы |
| `machine_pass false` по true peak −0.4 при норме LUFS | однопроходный `loudnorm I=-14:TP=-1` не держит пик | лимитер после loudnorm в `render.py` (исправлено); TP теперь −1.2 |
| Guardian не увидел поздние слои и коллизии с субтитрами | `qa.py` снимал один кадр на сцену | late-кадр 88 % сцены `scene-XX-<id>-late.jpg` (исправлено); guardian смотрит оба |
| Нужный отрезок скринкаста не показать в короткой сцене | слой `video` играл только с 0 с | поле `seek` (секунды) в `video` — схема, timeline, оба движка (исправлено) |
| Kicker ложится на заголовок | kicker `y` 196 и headline `y` 250 — зазор 54 px | headline `y` ≥ 260 при kicker; валидатор предупреждает при зазоре < 1.3·size kicker |
| Повторы стикеров и частые crash считали руками | валидатор не проверял правила библиотеки 3/6/9 | `validate_storyboard.py`: warning на стикер в соседних сценах, > 2 сцен на `src`, > 1 stamp/bignum, два crash ближе 5 с (исправлено) |
| Три захода QA из-за сдвигов «на глаз» | правки координат без пересчёта проекции | storyboarder сначала считает по формуле / смотрит warnings валидатора, потом двигает — одна правка |
| WebFetch HF Papers отдаёт подпись к SVG; GitHub — только шапку без README | рендер страниц JS-зависимый | MCP huggingface `hf_fs cat hf://papers/<id>`; GitHub — `raw.githubusercontent.com/<org>/<repo>/main/README.md`, статистика — `api.github.com/repos/...`; arXiv — `/html/<id>` (skill researcher) |
| Publisher не нашёл `qa/` для кадра обложки | publisher и guardian идут параллельно, `qa/` ещё не создана | указывать кадр обложки по `scene id` + таймкоду с fallback; Директор при склейке подставляет фактический `qa/hook.jpg` |
| Remotion падает на `waveform` / пустые столбики | `visualizeAudio` требует `numberOfSamples` = степень двойки; storyboarder ставил 24/28 | `layers.tsx` `pow2Samples` + slice (исправлено); `validate_storyboard.py` warning на bars ∉ {8,16,32,64}; дефолт timeline — 32 |
| Karaoke-субтитры слипаются («словослово») | `Captions.tsx` делал `tok.text.trim()` и съедал пробелы между токенами | `tokenText()` сохраняет ведущий пробел; karaoke margin 0.22em; storyboarder: karaoke только на коротких сценах, иначе `box` + `max_sec` 0.75 (исправлено) |
